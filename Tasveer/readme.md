# 📸 Tasveer – Instagram-Like React Native UI  

Tasveer is a **fully designed social media UI template** built with **React Native and Expo**, providing an Instagram-like experience.  
This project includes **chat features, stories, reels, and a feed UI**, ready for backend integration.  

## 🚀 Features  

✅ **Modern UI/UX** – Inspired by Instagram, built with clean and responsive design.  
✅ **Chat System** – Real-time messaging UI with voice notes and media sharing.  
✅ **Stories & Reels** – Full-screen short videos and images.  
✅ **Posts & Feeds** – Users can post and explore content seamlessly.  
✅ **Smooth Navigation** – Well-structured screens with fluid transitions.  

---

## 🛠 Prerequisites  

Ensure you have the following installed before running the project:  
- **Node.js** (Latest LTS version recommended)  
- **Watchman** (For macOS: `brew install watchman`)  
- **Xcode** (For iOS development)  
- **Android Studio** (For Android development)  

---

## 📦 Installation  

### 1️⃣ Install Node Modules  
```sh
npm i
```

### 2️⃣ Create iOS and Android Folders  
```sh
npx expo prebuild
```

### 3️⃣ Run on iOS  
```sh
npx expo run ios
```

### 4️⃣ Run on Android  
```sh
npx expo run android
```
